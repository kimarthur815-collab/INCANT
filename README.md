# INCANT

한글 타자로 주문을 외워 싸우는 마법사 결투 게임.

- 접두어(엠페럴, 슈퍼, 울트라, 엘레강스) + 주문(파이어볼, 홀리 쉴드, 리플렉트)을 치고 엔터로 시전
- 길게 칠수록 강하고, 빨리 칠수록 빠르게 날아가고, 오타 없이 치면 치명타
- 브라우저에서 바로 실행 (`index.html` 하나로 동작)
